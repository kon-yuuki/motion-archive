# Original replacement material and product imagery

All raster files here were created with the built-in image generation tool for this study. Original Duten textures, logos and product photographs are not bundled.

- original-silver-texture-v2.webp: smooth satin stainless steel with very fine diagonal grain. Source exec-fac3676a-ddbc-43b6-a643-e583992f6c7a.png
- original-black-texture.webp / original-brass-texture.webp: cropped from a three-material atlas. Source exec-3038418e-6987-4189-95e5-cddf528ee3ac.png
- original-{silver,black,brass}-product-{1,2,3}.webp: nine crops from an original generated3×3 photographic atlas of taps, dispensers and wall fittings. Source exec-d26a092f-7230-4628-9028-63ff06775e14.png

Product designs and material reflections/grain differ from the source. The family words match the recording (edstal, koveta, iflusse), but descriptions and product codes are original. Arial with a7px stroke at1600px reference size substitutes for the source font; surface/ substitutes for its logo. See ../meta.js for motion-model limitations.
