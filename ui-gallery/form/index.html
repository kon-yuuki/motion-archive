余白まで押せる

Best
受け取り方法

行全体がひとつの操作対象になる。ラジオ、文字、間の余白まで押せるので、読みながら自然に選べる。

行全体を押せます

Why it helps

押せる範囲が
見た目と合うと迷わない

体験として良くなること

ラベルを読んだ流れでそのまま押せる。小さな丸だけを狙わなくてよくなり、スマホや片手操作でも選択しやすい。

実装時に見るポイント

入力と文言を同じ label に入れるか、for と id を確実につなぐ。 同じ label に入れられない構造では、押せるようにしたい余白を親の gap ではなく、ラベル側の padding として持たせる。

狭い画面での注意

文字が折り返しても行全体を押せるようにする。タップ範囲は高さを保ち、フォーカス表示も行全体に出ると状態が伝わりやすい。

Implementation memo

余白まで押せるパターンは、ラジオと文言を同じ label に入れられるなら、それが一番素直です。 行全体がラベルになるので、見た目でひとまとまりに見える範囲と、実際に反応する範囲をそろえやすくなります。 

<label class="choice-option">
  <input type="radio" name="receiving" />
  <span>自宅へ配送</span>
</label>

構造上、入力と文言を同じ label に入れられない場合は、 余白を親要素の gap として置くと反応しない場所が残りやすい。 押せるようにしたい余白は、クリック対象になるラベル側の padding として持たせます。

入力とテキストがつながっていないため、反応するのは input 自体だけです。 文字を押しても選択は変わりません。 

<div class="choice-option">
  <input
    id="input-only-store"
    name="receiving"
    type="radio"
    value="store"
  />
  <span>店舗で受け取り</span>
</div>

for と id で入力とラベルはつながっています。 ただし、ラジオと文字の間にある親要素の余白はラベルではないため反応しません。 

<div class="choice-option">
  <input
    id="split-store"
    name="receiving"
    type="radio"
    value="store"
  />
  <label for="split-store">店舗で受け取り</label>
</div>

入力と文言を同じ label に入れられる場合は、行全体をラベルにします。 構造上それができない場合だけ、押せるようにしたい余白をラベル側の padding として持たせます。 

<label class="choice-option">
  <input
    name="receiving"
    type="radio"
    value="store"
  />
  <span>店舗で受け取り</span>
</label>
