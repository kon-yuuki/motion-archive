Motion Guide / 005

ScrollLinked

スクロール連動は、時間ではなく「ページをどれだけ進んだか」に合わせて変化する動きです。 読む速度に寄り添える一方で、動かしすぎると本文の邪魔になりやすい表現です。

Concept

スクロール量を、動きの進行度に変える。

通常のアニメーションは再生開始からの秒数で進みます。 スクロール連動では、要素が画面に入ってから抜けるまでを 0 から 100% として扱うと相談しやすくなります。

Target

Progress

0%

このページのスクロール位置から進行度を計算しています。スクロールすると、カードの位置と進行度が変わります。

Observe

読んでいる場所に合わせて、少しずつ変える。

スクロール連動は、変化量を小さくすると読みやすくなります。 見出しや画像の補助として使い、本文そのものを大きく動かし続けない方が安全です。

01

Fade

画面に入るにつれて透明度を上げる。内容が現れるタイミングを穏やかに伝える。

02

Shift

少しだけ上下に移動する。大きく動かすより、情報の流れが読みやすい。

03

Scale

画像や背景を少しだけ拡大する。主役の情報を邪魔しない範囲で奥行きを出す。

Language

「スクロールしたら動く」だけでは足りない。

どの範囲で、どの値からどの値へ変わるかを書くと、実装者が進行度を設計しやすくなります。

伝わりにくい言い方

スクロールに合わせて画像をいい感じに動かしてください。

伝わりやすい言い方

画像が画面下 80% に入ったら開始し、画面中央に来るまで opacity 0.4 から 1、translateY 24px から 0 に変化させる。

Request sample

そのまま使える指示文

スクロール連動では、開始位置・終了位置・変化する値・変化量をまとめて渡します。

セクション内の画像は、要素の上端が画面下 80% に入った地点を 0%、画面中央に来た地点を 100% とする。0% では opacity 0.45、translateY 24px。100% では opacity 1、translateY 0。本文テキストは動かし続けない。
