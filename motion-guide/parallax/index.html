Motion Guide / 007

Parallax

パララックスは、スクロールに対して手前と奥の動く速さを変え、奥行きを出す表現です。 要素そのものを動かす方法と、要素の中だけを動かす方法では、印象も実装条件も変わります。

Compare

視差を「どこにかけるか」を決める。

要素自体をずらすとレイアウト全体に動きが出ます。 要素内の画像だけをずらすと、車窓のようにフレームの中で景色だけが動きます。

Element parallax

要素自体に視差をつける

カードや画像ブロックの位置を少しずらす。画面全体に奥行きが出るが、重なりや余白の破綻に注意する。

Window parallax

要素内に視差をつける

フレームは固定し、中の画像だけを上下に動かす。車窓のような見え方で、レイアウトを崩しにくい。

Observe

スクロールすると、手前と奥の速さが変わる。

視差は「大きく動かす」より「違う速さで動く」ことがポイントです。 変化量を抑えると、奥行きは出しつつ読みやすさを保ちやすくなります。

Common language

Language

「パララックス」だけでは、実装が分かれやすい。

要素全体を動かすのか、フレーム内の画像だけを動かすのかを先に決めます。

伝わりにくい言い方

画像にパララックスを入れて、奥行きが出るようにしてください。

伝わりやすい言い方

画像フレームの位置は固定し、中の画像だけを上下に 32px 動かす。スクロール量に合わせ、中央に近づくほど元の位置に戻す。

Request sample

そのまま使える指示文

パララックスでは、対象、動かす範囲、速度差、はみ出し処理をセットで渡すと認識が揃います。

ヒーロー画像は、フレーム自体は固定し、内側の画像だけに車窓型のパララックスを入れる。画像は上下に最大 36px 動かすため、上下に余白を持たせる。テキストやボタンは視差を付けず、読める位置に固定する。
