Motion Guide / 003

Transform+ Opacity

UIの表示アニメーションでは、位置・大きさ・透明度を組み合わせることがよくあります。 大きく動かしすぎず、読める位置に出すことが大切です。

Compare

「何を動かすか」を決める。

opacity は見え方、translate は位置、scale は大きさを変えます。 実装者に渡すときは、どれを組み合わせるかまで書くと認識が揃います。

opacity

透明度だけ

落ち着いているが、どこから現れたかは伝わりにくい。補助的な表示に向いています。

translate + opacity

少し移動して表示

下から 12px だけ上がるなど、小さな移動を足すと出現の流れが分かりやすい。

scale + opacity

少し拡大して表示

中心から出る印象になる。モーダルやポップアップでは強さを控えめにすると読みやすい。

Build

移動量は、小さく始める。

画面の端から大きく入れると目立ちますが、読む邪魔になりやすいことがあります。 UIでは 8px から 24px 程度の移動でも十分に状態変化が伝わります。

Project update レビュー依頼を送信しました

次の担当者に通知されています。

透明度に加えて、下から 14px だけ上へ移動します。出現の方向が伝わり、動きも控えめです。

Language

「どこから出るか」を書く。

ふわっと表示する、だけでは opacity だけなのか、下から入るのか、拡大するのかが分かれます。

伝わりにくい言い方

通知カードを自然に表示してください。

伝わりやすい言い方

通知カードは opacity 0 から 1 にしながら、下から 14px だけ上へ移動する。拡大は入れない。

Request sample

そのまま使える指示文

対象、移動方向、移動量、透明度、秒数をまとめると、実装時のズレが減ります。

通知カードは表示時に opacity 0 から 1、translateY(14px) から 0 に変化させる。duration は 0.28 秒、最後に減速して止める。カード自体のサイズは変えない。
