# 3D asset attributions

The three GLB files below are extracted from the public Smooothy demo scene. Each upstream model's license was separately checked using the Sketchfab model API on 2026-10-03. The complete source scene is **not** shipped: extraction prunes other meshes, images, skins and binary views, including restricted models.

## Original replacements
The strawberry cake, octopus-style toast and ramen bowl in original-food.js are newly authored procedural meshes and textures. They are **not** extracted original models. The upstream sandwich is CC BY-NC, the cake uses a Standard commercial license, and the ramen's independent rights were not established. Those assets are excluded from the shipped files.

## Code observations
Panel cosine bending and independent food rotation were informed by the public MIT-licensed Smooothy implementation. The local renderer/controller is independently authored, and the shader noise/material animation, skeleton dynamics and exact inertia differ.
