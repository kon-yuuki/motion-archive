Rotating Scroll Gallery

縦に並ぶ画像列の上に、スクロール量で横に流れる固定タイトルを重ねるスクロール実験。画像の回転表現を追加する前のレイアウト土台。

共通の3D視点

奥行きは画像ごとに作らず、画像全体を包む親コンテナにだけ perspective を設定する。内側の画像リストと各画像カードは transform-style: preserve-3d で3D空間を引き継ぎ、すべての画像を同じカメラから見ている状態にしている。

カメラ位置の固定

perspective-origin のY座標を固定値にすると、長いページではスクロールに合わせて視点が上へ置き去りになる。そこで毎フレーム window.scrollY + window.innerHeight / 2 を --camera-y に書き込み、視点を常に画面中央へ合わせる。

ScrollTriggerの区間

各 data-gallery-item をトリガーにして、top bottom から bottom top までを1つのスクロール区間にする。前半で画像を中央へ向けて立ち上げ、後半で抜けていく状態へ戻すため、GSAPのタイムラインを2つの to() に分けている。

回転と見え方の同期

下端から中央までは rotationY を 0 から -180 へ、中央から上端までは -360 まで進める。rotationX は 16 → 0 → 16 として、正面に来る中央だけ傾きを消し、上下では少し寝かせて奥行きが読めるようにしている。

透明度とぼかし

同じタイムラインで opacity と filter も動かす。画像が画面中央に来る時だけ opacity: 1、blur(0px) にし、下から入る時と上へ抜ける時は opacity: 0.2、blur(10px) へ戻す。

固定テキストの分離

中央の横流れテキストは perspective を持つステージの外へ出している。親に3D変形がある中へ入れると position: fixed がビューポート固定ではなく親基準になるため、テキストだけ別レイヤーにして画面中央へ固定している。
