RGB Cursor Stalker

WebGL

FVはサブタイトルと1行タイトルを左揃えで置き、その下に5カラムのスクロールギャラリーを組んでいる。fine pointer環境だけDOM画像をWebGLのplaneへ置き換え、カード内のマウス座標を頂点変形、UV変形、RGBチャンネル分離へ同じ基準で渡している。

FVとギャラリー配置

FVは .rgb-copy を1カラムgridにし、align-content: end で画面下側の帯へ寄せている。サブタイトルと h1 は同じ左端に置き、タイトルは white-space: nowrap と幅別の clamp() で1行を維持する。

5カラムの余白設計

ギャラリーは repeat(5, minmax(0, 1fr)) と固定の行単位で組み、各カードに grid-column と grid-row を個別指定している。余白は row-gap と column-gap の clamp() で広げ、画像同士を重ねずにスクロール量で間を作っている。

WebGLの起動条件

finePointer が成立し、WebGLが使える場合だけ initRgbScene() を進める。タッチ環境では data-webgl-ready を付けないためDOM画像のまま表示され、CSS側の opacity: 0 へ切り替わらない。

DOMからplaneへの同期

resize() で各カードの getBoundingClientRect() を読み、stage左上を基準にmeshの中心座標を計算する。rectの幅と高さはmeshの scale と uPlaneSize へ入り、stage高から計算したcamera Zに合わせて camera.far も伸ばしている。

画像比率の保持

fragment shaderの coverUv() でplane比率と画像比率を比較し、表示に使うUV範囲を縮める。CSSの object-position は uObjectPosition に変換し、DOM画像とWebGL textureの寄せ位置を同じ計算へ通している。

カード単位の反応

stage座標へ変換したマウス位置を、各カードのrectと比較する。内側にあるentryだけ targetPointer を更新し、render loopで currentPointer へ補間してから uPointer としてshaderへ渡す。

放射方向の頂点変形

vertex shaderで各頂点の画面座標 screenPosition から uMouse を引き、カーソルから外側へ向かう radialDirection を作る。距離は smoothstep() で減衰させ、XY方向の押し出しとZ方向の持ち上げを同じ中心から発生させている。

UV変形とRGB分離

fragment shaderでも vScreen と uMouse から放射方向を作り、先に suctionUv でUVを少しずらす。そのUVを基準に、赤は放射方向へ、青は反対方向へ別々にサンプリングし、緑は基準UVの値を使って合成している。

停止時の戻し方

前回座標と現在座標の距離から motion を作り、動いていないフレームでは targetPointer が毎回減衰する。currentMouse は lerp()、currentPointer は補間で追従するため、カーソル停止後は頂点移動、UVずれ、RGBずれが同じ係数で戻る。

小さなDOMカーソル

丸いカーソルはshaderではなく data-rgb-cursor のDOM要素として重ねる。shaderへ渡す currentMouse と同じstage内座標を left と top に書き込むため、表示位置と変形中心が同じ座標系で動く。
