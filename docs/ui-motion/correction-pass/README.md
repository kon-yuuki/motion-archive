# 原作と比較した修正の確認ガイド

初回の30件は、部品が動くことと原作の見た目・動きが合うことを混同していました。ここでは原作の途中状態から作り直した範囲と、残る差を分けて記載します。すべてユーザーレビュー前のWIPです。

## この修正で変えたところ

- Dennis: 行単位のマスクを24個の単語マスクへ変更。作品一覧の画像・View円・文字を別々に追従させ、寸法と出入りの曲線を原作に合わせた
- Exo Ape: メニューの画像へ回転を戻し、縦長比率と文字配置を修正。リールは25%から等比で拡大し、左右の文字が中央に集まる。フッターの内容と背景は異なる速度で動く
- REJOUICE: 5枚で止まるレールを、9種類・2周分の複製と入力前からの移動へ作り直した
- More Nutrition: 5種類の循環、全体の入れ替えと内部のばねを分け、計測した300msと950msを反映
- Akaru: 開く時も閉じる時も境界が上へ進むようにし、閉じる間は内容を動かさない
- Noomo: セルごとの時差を、一つの斜めチェッカーマスクの移動へ変更。現在の公開CSSの148×43px、600ms、背景の遅延を反映
- テキスト5件: それぞれの原作の文字サイズ・配置・配色・素材へ戻し、元の順序と局所的な変化を保つよう作り直した。Casaの文字はライセンスのある代替書体なので字形が異なる
- B&O: 写真の折り畳み待機→短い展開→遅れた大文字、2枚のずれた写真ブロックと側面を再構成
- Duten: 小さな楕円を、文字全体へ広がる金属の帯へ変更。素材ごとの単語・製品・帯の形を切り替える

## 残る差と確認範囲

- 専用書体を再配布していないため、字形・太さ・端の形は違う。公開ライセンスの代替書体にはライセンスを同梱
- 元の写真・動画・ロゴは動作するデモに使わず、既存または新しく作った素材で代替。映像の質感まで同一とは主張しない
- 公開CSSから確定した値と、30fps映像・見た目から推定した値は各ページで区別する
- Akaruの文字の変形、Exoの画像の正確な時間、DICH/Black Dog/Fine/Dutenの元のシェーダーやノイズ関数、Casaの専用字形は未復元
- 原作の入力や自動再生を確認できないものは不明として残し、Replayの補助動作と混同しない
- キーボード・タッチ・小画面・動きを控える設定はデモ向けに補った部分がある
- 操作テスト、レイアウト寸法、輪郭・変換行列などの部分的な一致は、全体の忠実度やユーザー承認の代わりではない

この時点では25件の修正例を比較済みです。残るスライダー4件とLusionの立体シーンは別の修正段階で扱います。30件全体を完成・受け入れ済みとはしていません。
