## 初回実装の見た目の確認範囲（修正前）

コードの内部実装や元の意匠を複製したものではなく、観察した動きの仕組みを独立して再構成した学習用スタディです。画像・文章・ロゴは独自のものに置き換えています。

代表3件では、記録映像の途中フレームとデモの途中状態を比較しました。

- **Contour ripple**: 文字を形づくる水平線と、ポインター付近の局所的な盛り上がりを確認
- **Ferris-wheel gallery**: 広い画像が縦の立体的な並びへ狭まり、切り替え後に広がる仕組みを確認。原作の曲面に対して、この実装は平面の3D変形による近似
- **Organic mask**: 独立した小さな表示領域が成長し、全体へつながる仕組みを確認。原作の不規則なにじみに対して、この実装は独自の楕円形マスクによる近似

それぞれの違いは個別ページの「再現範囲と違い」にも記載しています。30件すべてのピクセル一致や、原作のタイミング定数の一致を保証するものではありません。
