# Codex Prompts

UI Gallery のデモ追加、改善、X投稿作成を Codex に依頼するときの定型プロンプトです。必要に応じて `<...>` を置き換えて使います。

## 新規UIデモを追加するプロンプト

```text
UI Gallery に `<テーマ名>` の挙動デモを追加してください。

対象は Motion Archive ではなく `ui-gallery/` です。
まずリポジトリ構成、既存の UI Gallery ページ、`package.json`、`vite.config.js`、`src/data/ui-gallery.js` を確認してください。

デモでは以下を含めてください。
- 何を検証するデモか
- よくある使いにくい挙動
- 改善した挙動
- なぜ使いやすくなるのか
- 実装時に見るべきポイント
- スマホや狭い画面での注意点
- X投稿用の短い説明文

文体は日本語で、デザイナーにも伝わる言葉にしてください。
いきなり専門用語から入らず、専門用語は必要な場合だけ実装メモに書いてください。
既存構成を壊す大規模リファクタリングはしないでください。

最後に、作成・更新したファイル、確認コマンド、確認できなかったことを報告してください。
```

## 既存デモを改善するプロンプト

```text
`ui-gallery/<slug>/` の既存デモを改善してください。

目的は、見た目を派手にすることではなく、UI の使いやすさがより伝わる比較デモにすることです。
まず対象ファイル、関連データ、既存の説明文、`package.json` の確認コマンドを確認してください。

改善観点:
- 悪い例と改善例の差が操作で分かるか
- なぜ使いやすくなるのかが本文で伝わるか
- 実装メモが具体的か
- スマホ、狭い画面、画面端、状態変化の注意点があるか
- X投稿に転用できる短い説明があるか

専門用語は必要な場合だけ補足に回し、デザイナーにも伝わる日本語にしてください。
不要な大規模リファクタリングはしないでください。
```

## デモからX投稿案を作るプロンプト

```text
`ui-gallery/<slug>/` のデモ内容を読み取り、X投稿案を作ってください。

以下の型から合うものを選び、2〜4案出してください。
- 比較デモ型
- あるある改善型
- チェックリスト型
- 実装メモ型

文体は日本語で、デザイナーにも伝わる言葉にしてください。
いきなり WCAG、ARIA、focus management、collision detection、prefers-reduced-motion などの専門用語から入らないでください。
必要な場合だけ、最後に実装メモとして専門用語を補足してください。

各案には、投稿本文と、添付する動画で見せるべき場面を短く添えてください。
```

## UI挙動の悪い例 / 改善例を洗い出すプロンプト

```text
`<テーマ名>` について、UI挙動の悪い例と改善例を洗い出してください。

対象は Web UI の小さな使いやすさです。
見た目の好みではなく、操作したときに迷わない、邪魔しない、読める、状態変化が伝わる、破綻しない、気持ちよく使える、という観点で整理してください。

出力してください。
- よくある使いにくい挙動
- その挙動でユーザーが困る理由
- 改善した挙動
- 改善で使いやすくなる理由
- 実装時に見るべきポイント
- スマホや狭い画面での注意点
- デモにするなら比較すべきパターン

専門用語は必要な場合だけ「実装メモ」にまとめてください。
```

## デザイナーにも伝わる説明文に直すプロンプト

```text
以下の説明文を、デザイナーにも伝わる UI 挙動デモの説明文に直してください。

条件:
- 日本語
- いきなり専門用語から入らない
- 「これはダメ」ではなく「こうすると使いやすくなる」で書く
- 抽象的な UX 論だけで終わらせない
- 実装目線の一言を添える
- 必要な専門用語は「実装メモ」か「補足」に回す

元の説明文:
`<ここに貼る>`
```

## 実装メモを追加するプロンプト

```text
`ui-gallery/<slug>/` のデモに実装メモを追加してください。

実装メモでは、コードの説明だけでなく、実装時に確認すべき条件を書いてください。
例:
- 表示位置
- 遅延時間
- 閉じる条件
- 画面端の処理
- スクロール時の追従
- 連続操作時の扱い
- キーボード操作
- スマホ時の代替UI
- 動きを控えたい設定への配慮

本文では専門用語を前面に出さず、必要な場合だけ実装メモ内で補足してください。
既存のページ構成と文体に合わせ、不要なリファクタリングはしないでください。
```
